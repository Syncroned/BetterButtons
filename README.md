# Better Edit Menu

Restructures the editor's **Edit** menu the way BetterEdit does, without the rest of the mod:

- Groups the move-object buttons into a compact directional menu instead of a long row
- Adds extra move-step buttons: quarter-grid (7.5u @ grid 30), eighth-grid (3.75u), and pixel (0.1u) steps

Each part can be toggled individually in the mod's settings.
